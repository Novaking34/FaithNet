Laptop #2 recharged for Field Kit 02 (cross-device room-air acoustics), we
executed both single-laptop kernel Field Kits live on Laptop #1
(`professorseanex-Inspiron-16-5640`, Linux `7.0.0-43-generic`, Go `1.26.8`):

   `OpResource` on Port `7777/udp`) across isolated kernel network namespaces

   delay, jitter, packet loss, bit-corruption, and 100% total blackout.

   Rung 1 Civilizational Floor `SerialTransceiver` (RFC 1055 SLIP) executing
   across real kernel `/dev/pts/3 <-> /dev/pts/4` TTY devices with worst-case
   `0xC0`/`0xDB` escape stuffing and mid-stream corrupt cable-glitch injection.
