== Gap #5 Exposed & Fixed: Why `.local` Timed Out (RFC 6762)

* **Root Cause:** Under **RFC 6762**, the `.local` TLD is reserved strictly for
  multicast DNS (Apple Bonjour / Linux Avahi). Both iOS and Ubuntu bypassed our
  unicast `dnsmasq` DNS server at `10.77.77.1:53` whenever resolving
  `faithnet.local`, broadcasting mDNS queries to `224.0.0.251:5353` that timed
  out.
* **Immediate Fix (Wave 10):**
  1. Added **`faithnet.lan`** and **`faithnet.home.arpa`** (RFC 8375 standard
     unicast home-network domain) to `dnsmasq` in `run_wifi_ap_router.sh`.
  2. Added **`faithnet.lan`** and **`faithnet.home.arpa`** to `collectLocalSANs()`
     in `interpreter/captive_web.go` so the Tier 2 Sovereign Root CA signs
     those domain names directly into the server certificate SANs.
* **Bonus Observation Logged:** Restarting `faithnet-home.service` preserved
  the Sovereign Root CA on disk while resetting the in-RAM 32-slot bulletin
  ring (`bulletins: 1 -> 0`)—confirming expected stateless RAM behavior today
  and flagging optional persistent bulletin storage for a future wave if wanted.
