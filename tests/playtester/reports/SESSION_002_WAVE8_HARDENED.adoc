== Bonus Distributed-Systems Discovery Caught During Session 002

During the first run of `REGIME 6`, Alpha successfully cascaded from silent-drop
`RUNG_3_LOCAL` to `RUNG_2_HOST`, yet Beta's `OpPong` disappeared because Beta
blindly replied on its highest rung (`RUNG_3_LOCAL`) instead of replying on the
rung that carried the `OpPing`!

Fixing this with `AdaptiveLadder.SendOnRung(in.Rung, ...)` in
`orchestrator/dispatcher.go` solved **asymmetric silent-blackhole replies across
all 4 rungs**—a classic distributed-networking failure mode that only real
adversarial playtesting uncovers.
