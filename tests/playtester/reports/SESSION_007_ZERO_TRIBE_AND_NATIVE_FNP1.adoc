== Gap #10 Caught Live & Sealed: Dual-Stack IPv4 + IPv6 WAN Firewall

During our first live `sudo faithnet-netctl mode island` test, IPv4 `iptables`
blocked `example.com` immediately—yet `curl https://example.com` **still
succeeded**!

* **Root Cause (Diagnosed in 1 Second):** `TheTribe` assigns a global **IPv6**
  address (`2600:6c40:...`) to `wlp3s0`. Blocking IPv4 alone left an IPv6
  escape path out `wlp3s0`.
* **Fix (`54b88f6`):** Sealed BOTH **`iptables` (IPv4)** and **`ip6tables`
  (IPv6)** inside `FAITHNET_WAN_GUARD` (inbound `DROP` on `wlp3s0`, preserving
  `ESTABLISHED,RELATED`, ICMP/ICMPv6 Neighbor Discovery, and DHCP/DHCPv6) and
  `FAITHNET_WAN_EGRESS` (`island` mode `REJECT` on both stacks).
