== Compatibility Without Dependency *(HTTP(S) Bridge vs. Native `faithnet://`)*

FaithNet was not built to pretend the modern internet does not exist. It was
built to end the silent assumption that **communication requires commercial
infrastructure to survive**.

[IMPORTANT]
====
**How Both Worlds Coexist Cleanly:**  
Today's legacy phones, laptops, and PlayStations expect **`http(s)://`**, so
FaithNet serves them gracefully via **The Well (`:8077`)** with an offline
Tier 2 Sovereign Root CA green padlock. Meanwhile, native FaithNet nodes—and
**MillenniumOS**, where FaithNet *is* the built-in internet layer—speak pure
zero-HTTP **`FNP/1`** (`faithnet://`, Port **`7777`**, verified live at
**`0.26 ms` RTT**!).
====

Modern internet architecture grew over 50 years by layering specialized
protocols—Ethernet, ARP, IPv4/IPv6, DHCP, DNS, BGP, TCP/QUIC, TLS, HTTP/3,
JSON/GraphQL, and cloud CDNs—assuming abundant bandwidth, always-on power,
trusted institutional registries, and central servers. That stack excels at
global streaming and cloud commerce, **but collapses catastrophically at the
local room and neighborhood edge whenever upstream power, fiber, or DNS breaks.**

[NOTE]
====
**Legal Boundary vs. Commercial ISPs:**  
FaithNet never pirates, spoofs, or bypasses commercial ISPs. In `island` mode
or with zero upstream Wi-Fi, commercial web traffic drops cleanly to **zero**
while local sovereign traffic runs strictly on lawful unlicensed ISM spectrum
(`2.4 GHz` / `5 GHz`). Legacy bridging (`bridge` mode) uses only the host
owner's own authorized connection behind a dual-stack IPv4+IPv6 inbound wall.
====

== Why the Compiled Trinity (C, Rust, Go) Matters Here

Modern web culture favors interpreted/dynamic runtimes (JavaScript/TypeScript,
Python) because they defer type, memory, and edge-case checks to runtime,
making Hour 1 feel fast when backed by cloud restarts.

For sovereign infrastructure and game engines alike, runtime-only error
discovery is a fatal liability:

* An **emergency fallback path** (such as Rung 1 Morse CW or an Airlock edge
  case) may never execute during sunny-day operation. In a dynamic runtime, a
  typo or type mismatch can sleep silently in that branch until the exact
  blackout night it is needed.
* Compiled native code (**C** for silicon/kernel, **Rust** for zero-cost
  structural tooling, **Go** for single-binary concurrent networking) forces
  every wire offset, error path, memory bound, and concurrency race to be
  settled *before* deployment—leaving **playtesting** free to expose real
  physical-world emergence instead of debugging typos in the dark.

== How FaithNet Speaks to the Modern World Safely

FaithNet bridges to existing OSes and the commercial web through **two tightly
guarded airlocks**—ensuring *compatibility without dependency*:

1. **Inbound Human/OS Bridge (`interpreter/` — "The Well"):** Existing phones
   and laptops talk plain HTTP over local Wi-Fi to The Well. Every message is
   screened by `covenant.Filter` and wrapped as `OpLegacyWrap` (`0:AWAIT`).
2. **Outbound Empirical Bridge (`transport/rung4_global/egress.go`):** Disabled
   by default (`AllowGlobalEgress = false`). When an operator explicitly opts
   in, remote web responses are bounded strictly to `481` bytes via
   `io.LimitReader` (preventing OOM DoS), screened through the Genesis 3
   Airlock, and quarantined as `0:AWAIT`.
