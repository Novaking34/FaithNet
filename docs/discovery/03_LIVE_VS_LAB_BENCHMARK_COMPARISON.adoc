== Why Three Benchmark Strata Are Required

A single benchmark number out of context misleads engineers. Saying *"FaithNet
UDP latency is 39 microseconds"* is true on Linux loopback — and **dangerously
false** if you use it to tune timeouts over crowded 2.4 GHz household Wi-Fi
where real packets experience `47–347 ms` of RF contention and power-save sleep!

FaithNet therefore tracks every capability across **three distinct evidence
strata**, all measured on the same primary host hardware
(`professorseanex-Inspiron-16-5640`, Linux `7.0.0-43-generic x86_64`, 12 CPU
cores, Go `1.26.8`, Realtek `RTL8852CE` Wi-Fi 6E):

1. **Stratum A — 4x4 Lab Matrix (`tests/{functional,unit,integrated,system}`):**
   Pure in-process deterministic benchmarks & race-detected correctness suites.
   Measures **algorithmic and CPU/memory ceilings** with zero OS/RF noise.
2. **Stratum B — Local-OS Playtester Harnesses (`tests/playtester/`, Sessions 001–002):**
   Real separate OS processes (`0 B` shared RAM), kernel TCP/UDP sockets, kernel
   FIFOs, real userspace chaos proxies, real 16-bit PCM `.wav` + `ffmpeg` codecs,
   and concurrent HTTP attack traffic. Measures **OS kernel & protocol resilience**.
3. **Stratum C — Live Physical Field Kit 01 (`Sessions 003–006`):**
   Real RF waves across four physical machines (`Inspiron-16-5640`,
   `Inspiron-5579`, iOS iPhone, Sony PlayStation), real browsers, real `hostapd`
   + `dnsmasq` + `iptables` NAT, real reboots, and real hotspot roaming.
   Measures **physical world & human-operator reality**.

== Engineering Thresholds Calibrated by Live Field Kit 01 Data

Comparing Stratum C (Live) against Strata A & B (Lab) drove five concrete
production design changes:

1. **Real Wi-Fi Jitter (`47.6–347.4 ms`) Validated 3-Second Beacon Cadence:**
   Any sub-200ms liveness assumption tuned on loopback (`39 us`) would have
   falsely declared healthy Wi-Fi peers dead during normal laptop sleep bursts.
2. **Dual-Mode Listener & Permanent `10.77.77.1` TLS SAN:**
   Added directly because real browsers force HTTPS and `systemd` boot order
   can start `faithnet-home.service` milliseconds before `ap0` receives
   `10.77.77.1`.
3. **Unicast `.lan` & `.home.arpa` Domains:**
   Added directly because real OS resolvers enforce RFC 6762 `.local` mDNS.
4. **Event-Driven `nmcli device monitor` Over 5-Second Polling:**
   Real `RTL8852CE` firmware locks instantaneously during a concurrent scan —
   so `5s` polling was too slow; real-time event monitoring reduced handoff
   reaction time to milliseconds.
5. **Cross-Platform `/pair.ps1` + Windows/macOS Kits:**
   Live self-replication proved how effortless one-command peer joining is,
   prompting immediate Windows PowerShell (`pwsh 7.7.0` tested) and macOS
   parity so any household device can join without installing Go.
