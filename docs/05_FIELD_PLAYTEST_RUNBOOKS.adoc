== Purpose

This volume documents how to execute the four physical-world **Field Kits**
staged inside `tests/playtester/field_kits/`—covering everything that requires
real consumer machines, room air, copper wires, or privileged kernel network
namespaces.

[IMPORTANT]
====
**Zero-Brick Safety Rule:** None of these runbooks permanently break host
networking, NetworkManager profiles, or default firewall policies on either
Laptop #1 (`professorseanex-Inspiron-16-5640`) or Laptop #2
(`seanje-lenox-wise-Inspiron-5579`). All AP, split-DNS, and dual-stack WAN
guard rules live inside isolated runtime chains (`FAITHNET_WAN_GUARD`,
`FAITHNET_WAN_EGRESS`) torn down cleanly on `systemctl stop faithnet-ap`.
====
