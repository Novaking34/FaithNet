== The Lab (`4x4 Matrix`) vs. The Field Lab (`tests/playtester/`)

FaithNet treats software assurance as two distinct disciplines that cannot
replace each other:

1. **The 4x4 Verification Matrix (`tests/{functional,unit,integrated,system}`):**
   **46 dedicated 5-Block test files** (`7` functional, `28` strict 1:1 per-cog
   unit, `6` integrated, `5` system) + `tests/common/fixtures.go` = **329
   verified test functions**, **22 live Block 4 pre-flight gates**, and **0
   data races** under `go test -count=1 -race ./tests/...`.
2. **The Playtester Proving Ground (`tests/playtester/`):** Live multi-process
   arenas, userspace chaos weather proxies, real kernel FIFO serial streams,
   real 16-bit PCM `.wav` acoustic torture benches, live TCP HTTP Well load
   tests, and physical **Field Kits**.

== Gaps Exposed in Session 001 & Closed in Wave 8 (Session 002 Verified)

None of the 329 passing lab tests flagged these three physical-world behaviors;
every one of them was surfaced directly by **Playtest Session 001**
(`tests/playtester/reports/SESSION_001_BASELINE.adoc`) and **closed and
empirically re-verified in Wave 8 / Playtest Session 002**
(`tests/playtester/reports/SESSION_002_WAVE8_HARDENED.adoc`):

1. **Silent Blackhole Blind Spot -> CLOSED (Wave 8):**
   Implemented `AdaptiveLadder.MarkRungDegraded` (zero-heap monotonic cooldown
   that never quarantines a node's sole surviving link), passive consecutive
   timeout tracking in `Dispatcher.PingPeer`, and reply-on-arrival-rung
   `AdaptiveLadder.SendOnRung(in.Rung, ...)` so peers never echo Pongs back
   into an asymmetric blackhole. *Session 002 proof:* `REGIME 6` rescued `2/2`
   pings automatically on `RUNG_2_HOST` after 3 silent UDP drops.
2. **Asynchronous Microphone Start-Offset -> CLOSED (Wave 8):**
   Upgraded `rung1_floor.DemodulateAFSK` with an energy-gated 4-sample sliding
   preamble correlator + +/-3-sample peak-contrast fine lock. *Session 002
   proof:* `0`, `5`, `16`, `40`, `200`, and `4,000` samples (`416.67 ms`) of
   leading silence now decode **`6/6` 100% bit-exact** while keeping `+3.93 dB`
   SNR and 32 kbps MP3 resilience.
3. **Real-LAN Wireless Jitter & Zero-Config Discovery -> CLOSED (Wave 8):**
   Added `DiscoverLANBroadcastIP()`, `UDPTransceiver.SetBroadcastAddr()`,
   self-broadcast echo filtering, `2000 ms` default LAN ping timeout, periodic
   3s LAN `OpBeacon` emission, and `--interactive` live operator REPL in
   `cmd/faithnet-node`.
