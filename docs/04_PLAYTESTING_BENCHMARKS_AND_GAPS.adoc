== The Lab (`4x4 Matrix`) vs. The Field Lab (`tests/playtester/`)

FaithNet treats software assurance as two distinct disciplines that cannot
replace each other:

1. **The 4x4 Verification Matrix (`tests/{functional,unit,integrated,system}`):**
   **46 dedicated 5-Block test files** (`7` functional, `28` strict 1:1 per-cog
   unit, `6` integrated, `5` system) + `tests/common/fixtures.go` = **329
   verified test functions**, **22 live Block 4 pre-flight gates**, and **0
   data races** under `go test -count=1 -race ./tests/...`.
2. **The Playtester Proving Ground (`tests/playtester/`):** Live multi-process
   arenas, userspace chaos weather proxies, real kernel FIFO serial streams,
   real 16-bit PCM `.wav` acoustic torture benches, live TCP HTTP Well load
   tests, and physical **Field Kits**.

== Honest Gaps Exposed by Playtesting (Driving Wave 8)

None of the 329 passing lab tests flagged these three physical-world behaviors;
every one of them was surfaced directly by **Playtest Session 001**
(`tests/playtester/reports/SESSION_001_BASELINE.adoc`):

1. **Silent Blackhole Blind Spot (`chaos_weather_proxy` Regime 4):**
   When `100%` of UDP packets were silently dropped (no OS socket error), all 5
   pings timed out while `AdaptiveLadder` stayed on `RUNG_3_LOCAL`.
   *Next Wave Action:* Implement heartbeat-driven passive degradation in
   `Dispatcher` (`N` missed Pongs -> degrade rung -> `EVT_CASCADE_DOWN`).
2. **Asynchronous Microphone Start-Offset (`audio_torture_bench` Section 3):**
   `DemodulateAFSK` decoded cleanly with `0` or `5` samples of leading silence
   (`<= 0.52 ms`), but failed at `>= 16` samples (`1.67 ms`) because preamble
   detection assumes bit-aligned sample index `0`.
   *Next Wave Action:* Add a sliding sample-by-sample energy gate + preamble
   correlator (`0xAA 0x55`) before running live Laptop #1 -> Laptop #2 room-air
   acoustic playtests.
3. **Real-LAN Wireless Jitter & Zero-Config Discovery:**
   Live ICMP to Laptop #2 (`192.168.1.99`) showed `47.6 ms` to `347.4 ms`
   power-save spikes (and another LAN peer dropped ICMP entirely behind a host
   firewall).
   *Next Wave Action:* Default real-LAN ping timeouts to `>= 1500 ms`, emit live
   UDP broadcast `OpBeacon` frames (`255.255.255.255:7777`), and add an
   interactive playtest REPL to `cmd/faithnet-node`.
